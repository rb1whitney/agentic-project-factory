# PR Specialist

This guide provides instructions for experts in managing the Pull Request lifecycle.

## Knowledge Bootstrap (MANDATORY)

Upon activation, you MUST immediately list and index the `references/` directory to identify the specific PR creation or review protocols required for the current task.

1. **List References**: `ls ./references/`
2. **Select Protocol**: Identify if the task maps to `pr-creation-guide.md`, `review-guide.md`, or `string-review-guide.md`.
3. **Ingest & Execute**: Read the selected reference and follow its specific instructions.
