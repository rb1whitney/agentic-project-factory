# Skill: Elite Product Blueprint

**Status**: [MANDATORY] | **Owner**: Factory Conductor

This blueprint codifies the 6-phase manufacturing lifecycle for all "Elite Products" built within this factory. No product shall be certified as "Shipped" unless it has adhered to every phase of this protocol.

---

## 🏗️ Phase 1: Product Initiation (The Vision)
- **Action**: Create an Amazon-style **Press Release (Working Backwards)**.
- **Goal**: Define the problem, solution, and customer benefit *before* writing code.
- **Requirement**: This document must live in the project root alongside the README.

## 🏗️ Phase 2: TDD Foundation (The Wall)
- **Constraint**: **NO IMPLEMENTATION CODE WITHOUT PERMISSION.**
- **Action**: Define the testing suite and edge cases (TDD-First).
- **Goal**: Establish the technical success criteria before the engine is built.
- **Requirement**: 90% test coverage mandate must be set at this stage.

## 🏗️ Phase 3: High-Fidelity Manufacturing (The Engine)
- **Constraint**: **REJECT REGEX FRAGILITY.**
- **Action**: Build core logic using high-fidelity parsing (AST, HCL2, etc.).
- **Goal**: Ensure the tool is robust, semantic, and production-grade.

## 🏗️ Phase 4: Zero-Zero Decoupling (The Autonomy)
- **Constraint**: **ZERO CROSS-BOUNDARY SYMLINKS.**
- **Action**: Enforce standalone independence from the first commit.
- **Requirement**: ALL agents and skills required by the product must be **PHYSICAL COPIES** in the project's internal cognitive folders. Symlinking back to the factory floor is strictly prohibited.
- **Note**: Use native, relative path resolution for all internal assets.

## 🏗️ Phase 5: Master Panel Audit (The Jury)
- **Action**: Conduct a 3-round "Good, Bad, Ugly" peer review using Non-Swarm specialists.
- **Requirement**: Every agent must judge their own **Competence** before critiquing.
- **Outcome**: Index technical debt for future hardening tracks.

## 🏗️ Phase 6: Certification (The Ship)
- **Action**: Update the **Production Ledger** (root `tracks.md`) and create a **Master Walkthrough**.
- **Status**: [SHIPPED]

---
*Governance: ALL AGENTS MUST OBSERVE THESE PHASES | TDD-FIRST IS THE LAW*
