# Design Tokens

## Canvas
- 16:9
- 1920×1080 logical design space
- 60px safe interior padding

## Palette

```text
Canvas Dark       #0F172A / #0B1026
Electric Blue     #3B82F6
Emerald           #10B981 / #2DD4BF
Warning Coral     #F87171
Card Slate        #151A3A / #1E293B
Border            #2A3163
Body              #CBD5E1 / #C9CDE3
White             #FFFFFF / #F4F5FA
```

Coral is reserved for risk, broken states, and unverified data.

## Typography

- Title: Arial Black or Poppins; 36–56px equivalent
- Card heading: 32–36px
- Body: 20–28px
- Hero number: 104–120px
- Minimum: 24px except code / tabular subtext where 20px is deliberately required

Use sentence case for titles.

## Design principle

Design strictly serves the argument.

Tokens are defaults, not a substitute for composition.
