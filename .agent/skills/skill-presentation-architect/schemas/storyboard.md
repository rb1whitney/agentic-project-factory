# Storyboard Schema

```yaml
storyboard:
  - slide: 1
    title: ""
    purpose: ""
    narrative_beat: ""
    audience_question: ""
    evidence: []
    visual_thesis: ""
    visual_form: ""
    content:
      - ""
    objection_addressed: ""
    transition: ""
    speaker_role: ""
```

A storyboard is intentionally lightweight. It is not a rendered slide specification.
