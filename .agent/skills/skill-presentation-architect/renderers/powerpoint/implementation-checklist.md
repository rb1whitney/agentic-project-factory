# PowerPoint Implementation Checklist

## Before rendering

- [ ] Narrative approved
- [ ] Storyboard approved
- [ ] Evidence statuses complete
- [ ] Unknowns preserved
- [ ] Slide specs generated
- [ ] Fonts available
- [ ] Output path established

## During rendering

- [ ] 16:9
- [ ] Safe margins
- [ ] Assertion title on every content slide
- [ ] Correct semantic colors
- [ ] Native/editable text
- [ ] Editable diagrams where practical
- [ ] Speaker notes
- [ ] No hidden overflow

## After rendering

- [ ] Render every slide to image
- [ ] Inspect every image
- [ ] Inspect thumbnail sequence
- [ ] Check title wrapping
- [ ] Check small text
- [ ] Check diagrams
- [ ] Check charts
- [ ] Check alignment
- [ ] Check evidence labels
- [ ] Check final ask
- [ ] Re-render after fixes
