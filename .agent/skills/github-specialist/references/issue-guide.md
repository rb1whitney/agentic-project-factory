# Issue Specialist

This guide provides instructions for experts in managing GitHub Issues and task tracking.

## Knowledge Bootstrap (MANDATORY)

Upon activation, you MUST immediately list and index the `references/` directory to identify the specific issue creation or breakdown protocols required for the current task.

1. **List References**: `ls ./references/`
2. **Select Protocol**: Identify if the task maps to `issue-creation-guide.md` or other task-tracking guides.
3. **Ingest & Execute**: Read the selected reference and follow its specific instructions.
