## Overview
Project **nit-fabric** is a deterministic reconciliation engine designed to manage the high-resolution connectivity backbone of an agentic factory across AWS, GCP, and GKE. It replaces "imperative HCL scripts" with a **Mathematical State Controller**.

## Core Value Propositions
1. **Deterministic Connectivity**: 100% alignment between HCL intent and cloud reality.
2. **Zero-Trust Sovereignty**: Mathematical enforcement of data boundaries.
3. **Operational Transparency**: Automated topology synthesis via Mermaid.js.
4. **AI-Driven Remediation**: Semantic failure investigation and HCL patching.
